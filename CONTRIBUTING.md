# Contributing

This repository is a published copy: the libraries are developed next to Blupinta's API, so that every change to the
API and to its clients is tested together before release.

- **Issues** are welcome here: bugs, questions, missing features.
- **Pull requests** are welcome too. An accepted change is applied upstream and comes back here with the next release,
  crediting its author; the pull request is then closed with a link to the release.
- Security problems: see [SECURITY.md](SECURITY.md), never a public issue.
